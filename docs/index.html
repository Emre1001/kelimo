Gegen Halluzinationen

Das Modell schlägt vor. Der Code entscheidet.

Kleine Sprachmodelle können sich irren. Deshalb vertraut Kelimo ihnen nie blind. Jede KI-Ausgabe muss fünf Stufen überstehen, sonst wird sie nicht angezeigt.

1

Fester Lösungsschlüssel

Übungen werden nie von der KI bewertet, sondern exakt gegen geprüfte Inhalte.

2

JSON-Schema

Die Ausgabe ist per Constrained Decoding an ein Schema gebunden. Kein Freitext-Chaos.

3

Faktenprüfung

Korrekturen müssen auf Text zeigen, den du wirklich geschrieben hast. Sonst fliegen sie raus.

4

Zweite Meinung

Ein unabhängiger zweiter Durchlauf bei Temperatur 0 muss jeder Korrektur zustimmen.

5

Ehrliche Labels

Was nicht geprüft ist, wird als KI-Inhalt markiert. Grammatik-Antworten nennen ihre Quellen.

100 % privat

Kein Versprechen. Eine technische Tatsache.

Kelimo fordert keine Internet-Berechtigung an. Android blockiert deshalb jede Verbindung, bevor sie entsteht. Das kannst du in der App selbst überprüfen.

FAQ

Gute Fragen.

Ist Kelimo wirklich kostenlos?
Ja. Keine Werbung, kein Abo, keine In-App-Käufe. Der Quellcode ist offen.
Warum hat die App keinen eigenen Download-Button für Modelle?
Weil sie dafür eine Internet-Berechtigung bräuchte. Ohne diese Berechtigung kann sie technisch gar nichts senden. Den einmaligen Download erledigt dein Browser.
Läuft das auf meinem Handy?
Lektionen laufen auf jedem Android 12+. Für die KI empfehlen wir 8 GB RAM oder mehr, ideal ist ein Galaxy S25 / S25+ oder vergleichbar. Mit 6 GB nimmst du Gemma 4 E2B.
Kann die KI mir falsche Grammatik beibringen?
Der Kurs und die Bewertung kommen nie von der KI. Korrekturen im Gespräch werden doppelt geprüft und nur gezeigt, wenn beide Prüfungen übereinstimmen. Unsichere Inhalte sind gekennzeichnet.
Funktioniert Sprechen offline?
Ja, mit der Offline-Spracherkennung von Android. Fehlt das Sprachpaket, nutzt Kelimo bewusst keine Cloud-Erkennung, sondern zeigt dir, wo du es installierst.
